PS5 browser diagnostics

Check which browser features your PS5 exposes and record Canvas behavior. This is NOT a jailbreak, an exploit verifier, or a way to run unsigned games.

Find it under Settings → System → System Software → Console Information. The webpage cannot reliably identify firmware automatically.

1. Safe diagnostics

Checks JavaScript features, typed arrays and ordinary Canvas rendering. These tests do not attempt to exploit security flaws.

2. Optional Canvas reentrancy experiment

Tests a reentrant getContext() option-getter behavior. May crash, freeze or close the PS5 browser. It does not include memory-reclaim spraying, arbitrary memory access, a payload or a jailbreak.

A particular result does not demonstrate a use-after-free vulnerability.

Diagnostic report
